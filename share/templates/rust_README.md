## Install

Copy (or symlink) the shared library to the MADS lib directory.  The loader
takes the agent name from the file stem, so drop the `lib` prefix and use the
`.plugin` extension to match the `[{{name}}]` settings section:

```sh
cp target/release/lib{{name}}.dylib "$(mads -p)/lib/{{name}}.plugin"   # macOS
cp target/release/lib{{name}}.so    "$(mads -p)/lib/{{name}}.plugin"   # Linux
```

| `-o KEY=VALUE` | Set a settings key (repeatable) |
| `--silent` | Suppress the per-message status line |
